# Why these checks

Researched 2026-11-18 (Exa search, sources read via search highlights; not every page fetched in full).

| Check | Named sources | How it is applied |
| --- | --- | --- |
| Minto pyramid | Barbara Minto, *The Pyramid Principle*; summary at mental-models.com/minto-pyramid ("ask 'So what?'... ask 'Why is that true?'") | Diagram, then vertical logic, MECE grouping, deliberate order |
| BLUF | Military and plain-language writing guidance; the user's `my-writing-style` profile | First sentence carries answer, decision or ask |
| A. Claim and evidence | Toulmin's claim/grounds/warrant model (1958); JoAnne Yates, MIT 15.279 "Constructing a Logical Argument" (test data and warrants: source, accuracy, relevance, sufficiency); Lundquist College Business Writing Guide, Univ. of Oregon ("eliminate unsupported claims") | Per claim: grounds offered, link stated or assumed |
| B. Reader objections | Bob Behn, "The Craft of Memo Writing" (Harvard Kennedy School: "Who might quarrel with the analysis?"); MIT 11.401 "Effective Professional Writing: The Memo" ("Are counter arguments considered?"); Danziger memo handout, Shorenstein Center ("anticipate... objections"); Yates (concede what you cannot refute) | Name the reader, list likely objections, mark answered or not |
| C. So-what | Minto relevance test (above) | One line per paragraph: what the reader should think or do |
| D. Hedging and vagueness | MIT 11.401 ("vague phrases"); Andrew Luxem business-writing playbook ("keep a qualifier when it expresses a real evidence limit") | Flag hedges hiding a decision, owner, date or number |

Evidence shape: A and B have the most independent support (four and four
named sources). C rests mainly on Minto. D is real but lighter, and overlaps
with the style profile's own don'ts. Doug chose to run all four.

## Widened research, 2026-11-18 (Exa, arXiv, Particle)

Folded into the skill:
- Minto's plural-noun grouping test and four allowed orders; so-what never cuts risks or next steps (msdbok.github.io SN C1, quoting Minto).
- Skim test on first sentences; reverse outline (Cynthia L. King, "Reverse Outlining", IEEE Trans. Prof. Comm., 2012; Vanderbilt writing guide).
- Short, anchored, question-heavy feedback: FOXGLOVE (Liu et al., arXiv 2606.06271) found LLM feedback rated higher largely because it was longer, and used fewer questions than instructors.
- Questions over rewrites: Prober.ai (Bi et al., arXiv 2605.05598) constrains the model to inquiry about weak arguments, grounded in Toulmin.

Podcast practitioners (Particle via Exa Agent; summaries, transcripts not read in full):
reverse outline (Thomas Andrews, Drafting the Past ep. 116); adversarial reader (Mark Butler, A Podcast for Coaches); address objections early (Wayne Pollock, Legally Contented); so-what cutting (Think Fast Talk Smart ep. 263); specific reader (Chad Prevost, The Difficulty); SCQA (My BrainWise Coach); read aloud (Susanna Schrobsdorff, This Might Work); revise structure before copy-editing (Natalie Wexler).

Not adopted: read-aloud and physical cut-up (human activities); SCQA (a drafting frame, useful as a question if no governing thought exists); Williams given-new flow (sentence-level; possible later check).

Checks chosen by Doug 2026-11-18: all four (A to D).
